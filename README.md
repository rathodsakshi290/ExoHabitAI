# 🌍 ExoHabitAI

An end-to-end Machine Learning project that predicts the habitability of exoplanets using planetary and stellar characteristics. The project combines data preprocessing, machine learning, Flask APIs, and a responsive web interface to provide real-time predictions.

---

## 📖 Project Overview

ExoHabitAI analyzes astronomical data to determine whether an exoplanet has the potential to support life. The application follows a complete AI pipeline, beginning with data preprocessing and ending with deployment as a web application.

---

## 🚀 Features

- Predict exoplanet habitability
- Clean and preprocess astronomical data
- Train Machine Learning models
- Generate habitability scores
- Flask REST API integration
- Interactive web interface
- Deployment-ready application
